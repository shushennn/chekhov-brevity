# Описание данных

## `data/raw/` — сырые тексты

**Источник:** [RusLit](https://github.com/d0rj/RusLit) — коллекция русской классики
в `.txt`, кодировка UTF-8. Автор датасета указывает источники текстов: LitLib,
Викитека, Ilibrary. Это не академические издания.

**Как получить:**

```bash
git clone --depth 1 https://github.com/d0rj/RusLit.git data/raw
```

**В репозиторий не входит.** Это чужой датасет, он уже опубликован, копировать его
сюда незачем. Папка перечислена в `.gitignore`.

**Правовой статус:** все тексты в общественном достоянии, авторы умерли более
70 лет назад.

**Что берём:** папки `Chekhov`, `Gorky`, `Bryusov`, `Tolstoy` внутри
`data/raw/prose/`. Один файл — одно произведение, имя файла — название. В каждой
папке есть `info.csv` с колонками `name,year` (год написания).

| автор | файлов в папке | в анализе | медианный год |
|---|---|---|---|
| Чехов | 77 | 73 | 1886 |
| Горький | 33 | 25 | 1899 |
| Брюсов | 30 | 30 | 1906 |
| Толстой | 42 | 42 | 1867 |

Медианный год считается только по текстам, у которых год записан числом:
у Чехова это 76 файлов из 77, у Толстого — 41 из 42.

**Известные дефекты:** у двух текстов год в `info.csv` не читается как число:
у «Драмы на охоте» Чехова он пустой, у «Корнея Васильева» Толстого записан
диапазоном `1905-1906`. В медиану они не входят.

Тексты не выверены по академическим изданиям. В некоторых
файлах есть редакторские шапки вида `РЕДАКТОРЫ: Г. А. ВОЛКОВ` — они попадают
в подсчёт наравне с авторским текстом. Доля таких строк ничтожна, но результат
формально ими загрязнён.

Выборка неполная и сформирована не нами: по какому принципу автор датасета отбирал
произведения, неизвестно. Заметное следствие — у Чехова преобладают ранние тексты
(медианный год 1886, то есть юморески для журналов).

## Что исключено из анализа и почему

Считаем только **повествовательную прозу**. Восемь текстов исключены поимённо,
список задан константой `EXCLUDED` в `analysis.ipynb`:

| автор | текст | причина |
|---|---|---|
| Чехов | Три сестры | пьеса |
| Чехов | Вишнёвый сад | пьеса |
| Горький | Мещане | пьеса |
| Горький | На дне | пьеса |
| Горький | Несвоевременные мысли | публицистика |
| Горький | Город жёлтого дьявола | очерк |
| Горький | Сказки об Италии | очерк |
| Горький | Человек | поэма в прозе |

**Пьесы** — сплошные реплики, короткие по устройству жанра, а не по воле автора.

**Публицистика, очерки и поэма в прозе** — другой тип речи. У Горького предложения
в них заметно длиннее, чем в его же рассказах: исключение этих четырёх текстов
меняет его среднюю с 12,9 до 11,6 слова.

Дополнительно **исключаются тексты короче 50 предложений** — среднее по ним слишком
шумное. Порог задан константой `MIN_SENTENCES`.

## `data/processed/works.csv` — свод по произведениям

Строится ноутбуком `analysis.ipynb` из `data/raw/`.
Одна строка — одно произведение, всего 170 строк.

| колонка | тип | описание |
|---|---|---|
| `author` | строка | `Chekhov`, `Gorky`, `Bryusov` или `Tolstoy` — имя папки в датасете |
| `title` | строка | название произведения (имя файла без `.txt`) |
| `n_sentences` | целое | число предложений в тексте по разметке `razdel` |
| `mean_sentence_len` | дробное | средняя длина предложения в словах |

**Как считается длина предложения.** Границы предложений размечает
[razdel](https://github.com/natasha/razdel), слова считаются делением по пробелам
(`len(text.split())`). Знаки препинания при этом прилипают к словам и отдельными
токенами не считаются.
